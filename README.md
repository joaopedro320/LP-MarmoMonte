# LP MarmoMonte

Deploy: arrastar a pasta no Vercel (projeto estatico, sem build) ou `vercel --prod`.

## Antes de publicar
1. `GTM-XXXXXXX` -> ID real do container (2 ocorrencias no index.html)
2. `ENDPOINT_FORM` -> URL do Apps Script (topo do bloco <script>)
3. Baixar do site atual e salvar em /img, depois trocar os caminhos:
   - HORIZONTAL-FP-768x181.png -> img/logo.png (header e rodape)
   - cropped-favicon_marmomonte-270x270.png -> img/favicon.png
   - FOJ02E801, Granito-Preto-Sao-Gabriel, quartzito.png, translucido.png, laminas.png -> img/mat-*.jpg
4. Endereco completo e CEP de Capao da Canoa no JSON-LD
5. Bloco de prova social esta comentado, aguardando GMN corrigido e depoimentos
